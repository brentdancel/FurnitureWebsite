# FURNITURE HTML AND CSS EXERCISE

# Purpose
This project was done during my time in ERALLC Solutions HTML and CSS Course.

# Tools Used
Host Machine (Laptop/PC)  
Visual Studio Code  

# Learning Objectives
Understand HTML and CSS Fundamentals
Learn how to use Visual Studio Code
Know and Develop Web Development Best Practices  

# How to Use
I would recommend installing Visual Studio Code with the following Extensions:  
Prettier - Organizes code  
Live Server - Allows live display of html page  

Minimal JavaScript within the HTML file. Focus on HTML and CSS fundamentals. Understand what each element does and how style affects elements

If time passes, open up a new project and just type the code to understand what elements are and how everything interacts with one another
